# iina/

## OVERVIEW
Main macOS app (AppKit) + playback engine integration (libmpv) + plugin runtime + preferences + localization/assets.

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Startup + URL scheme routing | `iina/AppDelegate.swift` | registers `kAEGetURL`; routes `iina://open` / `iina://weblink` |
| Playback API surface | `iina/PlayerCore.swift` | keep high-level playback logic here |
| mpv bridge + options | `iina/MPVController.swift` | libmpv lifecycle, event queue, option mapping |
| Render lifecycle | `iina/VideoView.swift` | render teardown; shutdown safety notes |
| Main window behavior | `iina/MainWindowController.swift` | OSC, sidebar, fullscreen/PiP, UI sync |
| Preferences keys/defaults | `iina/Preference.swift` | canonical keys and defaults |
| Preferences UI | `iina/Pref*ViewController.swift` | per-tab settings; some changes apply live |
| Plugin runtime discovery/install | `iina/JavascriptPlugin.swift` | loads from Application Support/plugins; supports install from Git / package |
| Plugin JS bridge | `iina/JavascriptMessageHub.swift` | `window.iina` message bridge |
| Plugin surfaces | `iina/PluginOverlayView.swift` `iina/PluginSidebarView.swift` `iina/PluginStandaloneWindow.swift` | inject bridge into webviews |
| Generated mpv bindings | `iina/MPVCommand.swift` `iina/MPVOption.swift` `iina/MPVProperty.swift` | generated by `other/parse_doc.rb` |

## CONVENTIONS (LOCAL TO iina/)
- `CONTRIBUTING.md` "current structure" is the source of truth:
  - Only `VideoView` and `MPVController` may call mpv APIs directly.
  - `PlayerCore` encapsulates playback logic; setting options/properties through `MPVController` directly is discouraged.
  - Window-related logic belongs in `MainWindowController`.

## ANTI-PATTERNS
- Don't touch mpv directly from random UI/controllers; route via `PlayerCore`.
- Don't edit `MPV{Command,Option,Property}.swift` directly; regenerate with `other/parse_doc.rb`.
- Avoid committing spurious `.xib` changes unless you actually changed UI.

## NOTES
- Large hotspots (read before invasive edits): `iina/MainWindowController.swift`, `iina/PlayerCore.swift`, `iina/MPVController.swift`, `iina/AppDelegate.swift`, `iina/Preference.swift`.
- Localization: per `CONTRIBUTING.md`, only update strings in `iina/Base.lproj` and `iina/en.lproj`.
