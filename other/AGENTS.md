# other/

## OVERVIEW
Repo tooling scripts: download prebuilt dependencies, regenerate mpv bindings, adjust dylib install names, and maintain Info.plist document-type icons.

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Download prebuilt dylibs | `other/download_libs.sh` | populates `deps/lib` and `deps/executable` |
| Regenerate mpv bindings | `other/parse_doc.rb` | scrapes mpv manual and generates `MPV{Option,Command,Property}.swift` |
| Re-vendor dylibs | `other/change_lib_dependencies.rb` | copies dylibs into `deps/lib` and fixes install names |
| Update doc-type iconsets | `other/integrate_doc_types.rb` | regenerates `iina/Assets.xcassets/DocIcons/*` and writes `iina/Info.plist` |

## ANTI-PATTERNS
- Don't edit generated mpv bindings in `iina/` directly; change generator (`other/parse_doc.rb`) and regenerate.
- Don't hand-edit doc-type iconsets under `iina/Assets.xcassets/DocIcons/` if they are being regenerated by `integrate_doc_types.rb`.

## NOTES
- `other/parse_doc.rb` fetches `https://mpv.io/manual/stable/` and uses Nokogiri to emit Swift constants plus a hard "DO NOT DIRECTLY MODIFY" header.
